# Hidden Craft Teach

This is an example dApp for supporting art/craft projects via crypto donations on a testnet chain. It features:

- Wallet connection (MetaMask, WalletConnect, etc.)
- Crypto donations to a DAO address per art/craft
- Testnet support (Sepolia, Goerli, Mumbai, etc.)
- Sensory.ai integration for a tutor/assistant experience
- Custom UI (to be implemented)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Connect your wallet and donate testnet ETH/MATIC to support a DAO.

## Tech Stack
- Next.js
- React
- RainbowKit + Wagmi + Ethers.js
- Sensory.ai (for tutor/assistant)

## Customization
- Replace the DAO address and art/craft data as needed.
- Build your own UI and features on top of this template.
